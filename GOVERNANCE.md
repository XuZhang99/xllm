xLLM is developed by the xLLM community under the
[xLLM-AI](https://github.com/xLLM-AI) GitHub organization and hosted in OpenAtom Foundation.

Core maintainers shape the roadmap, review contributions, coordinate releases,
and support contributors. Update this roster when a maintainer joins or steps
down.

## Decisions

Discuss proposals in GitHub issues and pull requests, seek agreement, and record
the outcome there. Routine contributions follow the
[contribution guide](.github/CONTRIBUTING.md) and review by the relevant code
owners.

Decisions about project scope, release policy, maintainer membership, or
governance need approval from a majority of all active core maintainers listed
above. Silence and abstentions do not count as approval.

## Adding Maintainers

An existing core maintainer can nominate a contributor who has made substantial
contributions and participated in xLLM maintenance for at least three months.
Contributions can include implementation, reviews, documentation, testing, and
helping users.

Record the nomination and approvals in a GitHub issue or pull request. Apply the
majority rule above, then update the roster after approval.

## Governance Changes

Propose amendments through a pull request explaining the change. Adoption needs
the same majority approval from the current active core maintainers.
